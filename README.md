# Personal Portfolio Website

Welcome to my personal portfolio website! 👋

This website is a simple online portfolio where I showcase my skills, projects, interests, and basic information about myself.

## 🌐 Live Website

**Portfolio: https://samfolio-sepia.vercel.app/

## 📌 About the Project

I created this portfolio to build my online presence and practice my web development skills.

The website contains information about me, my technical skills, projects I have worked on, and ways to connect with me.

## ✨ Features

* Personal introduction
* About Me section
* Skills section
* Projects section
* Contact/social media links
* Resume section
* Responsive design for different screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
portfolio/

│   └── ...
```

## 🚀 How to Run

You can run the website locally by downloading or cloning this repository and opening:

```text
index.html
```

in a web browser.

## ☁️ Deployment

The website is deployed using **Vercel**.

Every time I update the website, I can push the changes to GitHub and redeploy the latest version.
